# Student Management System

A backend-based Student Management System built using Java, Spring Boot, Spring Security, Spring Data JPA, PostgreSQL, Kafka, and REST APIs.

## Features

- Admin login and dashboard
- Student management
- Teacher management
- Role-based authentication and authorization
- Student attendance management
- Kafka-based student login event handling
- Email notification on student login
- Forgot password with OTP verification
- PostgreSQL database integration
- Global exception handling
- REST API structure
- Thymeleaf-based frontend pages

## Tech Stack

- Java
- Spring Boot
- Spring Security
- Spring Data JPA
- PostgreSQL
- Apache Kafka
- Thymeleaf
- Maven
- Lombok
- Postman

## Project Modules

- Admin Module
- Student Module
- Teacher Module
- Attendance Module
- Authentication Module
- Forgot Password Module
- Kafka Event Module
- Email Notification Module

## Purpose

This project was created to practice backend development, authentication, authorization, database handling, Kafka integration, and real-world Spring Boot project structure.
